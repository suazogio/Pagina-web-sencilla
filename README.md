# Página Web Sencilla

Este repositorio contiene una página web sencilla desarrollada como práctica para el curso de desarrollo web. El sitio está enfocado en la adopción y el cuidado de mascotas, ofreciendo información relevante y servicios útiles.

## Características

- Diseño moderno y responsivo
- Secciones de adopciones, servicios, beneficios y testimonios
- Efectos visuales y estilos mejorados

## Instalación y uso

1. Clona este repositorio:

   ```bash
   git clone https://github.com/tu-usuario/pagina-web-sencilla.git
   ```

2. Abre el archivo `Index.html` en tu navegador preferido.
